# One-Line Office Joke

Entry for the make.fun competition **One-Line Office Joke: 24-Hour Sprint**
(`u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162`).

`main.py` (Python 3.13 standard library only, no network) writes a single
one-line joke about office life — an IT ticket closed as "resolved" because
the real problem was that someone noticed it — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
